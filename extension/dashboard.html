Текст открытых вкладок или страниц из истории — в локальном ZIP. Чтение идёт в фоне, без переключения ваших вкладок. Эта вкладка управляет обходом: оставьте её открытой.

Настройки обхода

Уточнить признаки готовности Delta

Необязательно. CSS-селекторы проверяются на каждой странице. Неверный селектор приведёт к явной ошибке.

«Начать заново» запускает новый бэкап без прежних снимков и попыток. Старый остаётся в истории. Для вкладок перечитывается текущий список Delta; для бэкапа истории — его выбранные ссылки.

Разрешение групп необязательно: без него сохраняются ID групп и окна. Выгруженные из памяти вкладки загружаются заново. При видимом сообщении «попробуйте перезагрузить страницу» выполняется перезагрузка в пределах настройки выше. Скрытый за кнопками или свёрнутыми блоками текст автоматически не открывается.

Отдельная опция: Delta из истории браузера

Найдите ссылки, выгрузите список URL или сохраните текущий текст выбранных страниц. История не содержит прошлые версии документов и названия прежних групп вкладок.

При первом поиске браузер запросит доступ к истории. Это разрешение охватывает историю профиля; расширение ищет Delta и сохраняет только ссылки точного домена delta.yandex-team.ru. Разрешение не требуется для бэкапа открытых вкладок.

Предыдущие бэкапы

Каждая вкладка сохраняется в локальную базу расширения сразу после чтения. Закрыли панель — откройте её снова и нажмите «Продолжить». Старые бэкапы доступны здесь; удаление расширения удалит и его базу.

Архив выбранного бэкапа: сырые файлы и папка «Чистые» с текстами в .md. Названия файлов — первые непустые строки документов.
